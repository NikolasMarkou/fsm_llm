# API snapshot

The public API of the library as one text file: the static `__all__` of the packages and
the named core modules, each name with its signature. It is generated by
`scripts/api_snapshot.py` (`make api-snapshot`) and a test fails when it differs from the code,
so this page is never older than the source it was built from. For a rendered, searchable view
of the same names read the module pages under Reference.
